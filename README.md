# IRON FRONTIER
A small original 2D factory-defense prototype made with LÖVE (Love2D).

## Run
Install LÖVE 11.4 or newer, then open this folder with LÖVE:
`love .`

## Mobile
The prototype supports touch input. Tap a build button along the bottom, then tap an empty tile. It can be packaged for Android with the LÖVE Android workflow.

## Controls
- Touch: choose a building at the bottom, then tap the map to place it.
- Desktop: 1 = miner, 2 = conveyor, 3 = turret, 4 = wall; left mouse to place.

## Current prototype
- Resource deposits and miners that generate iron
- Conveyor visuals
- Turrets that automatically attack nearby enemies
- Core health and enemy waves
- Original placeholder graphics drawn in Lua; no external assets required yet

This is an original project inspired by factory-building and tower-defense mechanics. It does not include Mindustry code or artwork.
